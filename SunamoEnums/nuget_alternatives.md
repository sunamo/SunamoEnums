# NuGet Alternatives to SunamoEnums

This document lists popular NuGet packages that provide similar functionality to SunamoEnums.

## Overview

Enum utilities

## Alternative Packages

### System.Enum
- **NuGet**: System.Runtime
- **Purpose**: Built-in enum operations
- **Key Features**: Parse, GetValues, GetNames, HasFlag

### Enums.NET
- **NuGet**: Enums.NET
- **Purpose**: High-performance enum library
- **Key Features**: Fast operations, attributes, descriptions

### SmartEnum
- **NuGet**: Ardalis.SmartEnum
- **Purpose**: Type-safe enum replacement
- **Key Features**: Rich domain models, behaviors, validation

### Humanizer
- **NuGet**: Humanizer
- **Purpose**: Enum humanization
- **Key Features**: Display names, descriptions, casing

## Comparison Notes

Built-in Enum methods for basic operations. Enums.NET for performance. SmartEnum for rich enumerations.

## Choosing an Alternative

Consider these alternatives based on your specific needs:
- **System.Enum**: Built-in enum operations
- **Enums.NET**: High-performance enum library
- **SmartEnum**: Type-safe enum replacement
